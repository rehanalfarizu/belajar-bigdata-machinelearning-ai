# Exercises

1. Hitung storage/bandwidth untuk 10.000 asset × 20 sensor × 1 Hz, termasuk burst, replication, dan retention.
2. Desain idempotent ingestion dengan duplicate, out-of-order, poison message, dan replay.
3. Pilih SQL, time-series, object, cache, dan graph store hanya bila access pattern membutuhkannya.
4. Definisikan tiga SLO dan error budget; buat alert yang actionable.
5. Rancang zero/low-downtime schema migration dan rollback.
