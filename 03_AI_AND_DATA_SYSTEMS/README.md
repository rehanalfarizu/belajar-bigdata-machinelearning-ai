# Phase 3 — AI and Data Systems

## WHY

Notebook yang akurat belum menjadi sistem. Fase ini mengajarkan modality AI, data skala besar, deployment, reliability, observability, dan cloud boundaries.

## LEARN

Computer vision, NLP/Transformer, distributed data, streaming, MLOps, APIs, containers, monitoring, security, dan architecture cloud.

## ORDER

`01 Computer Vision` → `02 NLP & Transformers` → `03 Big Data` → `04 MLOps` → `05 AI Systems & Cloud`.

## OUTPUT

Layanan inference/data pipeline yang tervalidasi, observable, idempotent pada boundary yang dipilih, dan mempunyai runbook serta rollback.

## GATE

Lanjut bila dapat menjelaskan failure semantics, schema compatibility, backpressure, degraded mode, model/data monitoring, dan recovery dari dependency failure.
