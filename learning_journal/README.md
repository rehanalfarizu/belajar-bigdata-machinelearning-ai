# Learning Journal

Buat satu file per minggu dengan nama `YYYY-Www.md`. Journal adalah evidence keputusan dan pembelajaran, bukan ringkasan semua bacaan.

## Template

```text
# Week YYYY-Www

Goal:
Chapter/project:

## Yang saya bangun
Artefak dan cara menjalankan:

## Hypothesis → experiment → result
Pertanyaan:
Hipotesis:
Perubahan tunggal:
Metric/baseline:
Hasil:
Keputusan:

## Failure/debugging
Gejala:
Evidence:
Akar masalah:
Perbaikan:
Test pencegah regresi:

## Reasoning dan trade-off
Keputusan:
Alternatif:
Mengapa dipilih:
Apa yang dapat mengubah keputusan:

## Reflection
Yang sekarang dapat saya jelaskan:
Gap berikutnya:
Bukti untuk progress tracker:
```

Jangan simpan secret, data personal/sensitif, atau output generated besar di journal.
