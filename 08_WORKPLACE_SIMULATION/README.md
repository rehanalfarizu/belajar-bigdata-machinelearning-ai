# Phase 8 — Workplace Simulation

## WHY

Tutorial memberi jalur; pekerjaan nyata memberi konteks tidak lengkap. Di sini kamu bertindak sebagai engineer dengan requirement, bug, log, incident, PR, atau architecture problem—tanpa solusi langkah demi langkah.

## LEARN

Clarification, prioritization, diagnosis, review, communication, risk, rollout, rollback, incident response, dan design defense.

## ORDER

Kerjakan `tickets` → `debugging_cases` → `code_reviews` → `pull_request_cases` → `incidents` → `architecture_cases` → `interview_cases` sesuai fase yang telah lulus.

## OUTPUT

Plan, questions, decision log, patch/design, tests, review notes, operational evidence, dan reflection.

## GATE

Tidak ada solution langsung. Lulus bila acceptance criteria terpenuhi dan keputusan dapat dipertahankan di bawah constraints serta failure scenario.

## PROJECT

Gunakan case ini sebagai evidence professional phase dan final capstone defense.
