# Problem-Solving Ladder — Python Fundamental

## Level 1 — Recall

Hitung rata-rata tiga angka. Sebelum coding, tulis input, output, state, dan zero-division case.

## Level 2 — Apply

Terima list campuran angka dan input invalid. Abaikan hanya value yang rule-nya menyatakan invalid, lalu laporkan accepted/rejected counts.

## Level 3 — Analyze

Program crash pada list kosong ketika menghitung min/max/mean. Jelaskan root cause, contract options, dan bagaimana caller mengetahui “tidak ada data”.

## Level 4 — Design

Rancang pemrosesan file sensor besar tanpa memuat seluruh file. Pisahkan parsing, validation, aggregation, quarantine, dan report.

## Level 5 — Debug / Workplace

Process crash di tengah file besar dan harus dapat resume tanpa menggandakan hasil. Nyatakan checkpoint state, idempotency boundary, corrupt-line policy, evidence, dan limitations. Implementasi penuh belum diwajibkan, tetapi design harus dapat diuji.
