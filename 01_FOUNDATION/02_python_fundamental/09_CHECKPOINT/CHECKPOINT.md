# Checkpoint — Python Fundamental

## Explain in your own words

- name binding, type/value, mutability/aliasing;
- list/tuple/set/dict selection;
- condition boundaries dan loop termination;
- function parameter/return, scope, dan exception propagation;
- file handle, module import, CLI arguments/exit code.

## Coding from blank file

Tanpa copy-paste, tulis program yang membaca input kecil, memvalidasi, menghitung summary melalui functions, dan menghasilkan error actionable. Trace satu input valid dan satu invalid.

## Required evidence

- notebook restart-and-run-all;
- exercises Level 1–4;
- minimal empat broken cases dengan prevention;
- Sensor Log CLI dan run instructions;
- reasoning challenge tentang streaming/resume;
- jawaban checkpoint dan tanggal.

## Gate

Lulus bila code dapat dijelaskan baris demi baris, tidak bergantung pada notebook state tersembunyi, module dapat diimport, dan error tidak diubah diam-diam menjadi value valid.
