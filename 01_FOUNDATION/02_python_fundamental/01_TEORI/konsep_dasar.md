# Peta Konsep Python Fundamental

File ini adalah entrypoint kompatibel, bukan lagi ringkasan seluruh Python. Mulai dari [Lesson 1 — Program Execution & Variable](01_execution_variable.md), lalu ikuti [chapter map](../README.md).

```text
source statements
→ names menunjuk values/objects
→ expressions menghasilkan values
→ collections menyimpan banyak values
→ conditions/loops mengatur flow
→ functions membuat contract
→ exceptions menyatakan failure
→ files/modules/CLI menghubungkan program ke dunia luar
```

Pada setiap contoh gunakan [Learning Protocol](../../LEARNING_PROTOCOL.md): prediksi, jalankan, amati state/output, jelaskan, modifikasi satu hal, lalu verifikasi.
