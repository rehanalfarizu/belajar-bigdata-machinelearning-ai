# Exercises

1. Ubah dictionary telemetry menjadi immutable dataclass dengan validation boundary.
2. Buat context manager untuk membuka resource dan buktikan cleanup tetap terjadi saat exception.
3. Refactor function yang menangkap `Exception` menjadi failure handling yang spesifik.
4. Tulis generator yang membaca event tanpa memuat semua data, lalu test empty dan malformed input.
5. Bandingkan solusi sequential dan async untuk tiga request simulasi; jelaskan kapan async tidak membantu.
6. Buat unit test, integration test, dan satu property/invariant test untuk package kecil.
