# Exercises — Python Professional

## Level 1 — Recall

1. Bedakan module, package, distribution, dan environment.
2. Bedakan runtime validation, type hint, dan test.
3. Jelaskan iterator exhaustion, context cleanup, dan exception propagation.

## Level 2 — Apply

1. Refactor dictionary reading menjadi dataclass dengan invariant.
2. Tulis generator line parser dan context manager timer.
3. Tambah named logger dan validated config dataclass.
4. Tulis unit tests success/boundary/failure.

## Level 3 — Analyze

1. Temukan circular import dan ubah dependency direction.
2. Bandingkan inheritance dengan composition untuk repository adapter.
3. Analisis broad exception dan retry decorator pada non-idempotent operation.
4. Temukan blocking call dalam async flow.

## Level 4 — Design

1. Rancang public API package sensor dengan domain/io/cli boundaries.
2. Rancang exception taxonomy, log events, config precedence, dan test pyramid kecil.
3. Rancang bounded concurrency untuk banyak simulated I/O jobs.

## Level 5 — Debug / Workplace

Selesaikan empat broken cases dan satu package install failure dari clean environment. Tunjukkan regression test dan rollback/change note.
