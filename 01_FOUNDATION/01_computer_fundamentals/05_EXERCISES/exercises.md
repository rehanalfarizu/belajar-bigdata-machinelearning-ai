# Exercises — Computer Fundamentals

Kerjakan setelah tujuh lesson. Untuk setiap jawaban tulis prediksi, evidence, dan penjelasan.

## Level 1 — Recall

1. Bedakan program, process, CPU, RAM, dan storage dengan satu contoh.
2. Definisikan working directory, relative path, absolute path, IP, port, DNS, HTTP, JSON, dan commit.
3. Urutkan working tree, staging area, dan commit.

## Level 2 — Apply

1. Jalankan source yang sama dua kali dan buktikan PID berbeda.
2. Tunjukkan relative path yang resolve berbeda dari dua cwd.
3. Set environment variable dan baca dari child process.
4. Jalankan local server dan identifikasi listener port.

## Level 3 — Analyze

1. Diberi `FileNotFoundError`, buat minimal lima hypotheses dan test pembeda.
2. Bedakan connection refused, timeout, HTTP 404, dan invalid JSON.
3. Jelaskan mengapa `git add` tidak membuat commit dan `git push` tidak mengirim working tree.

## Level 4 — Design

1. Rancang startup check untuk config path, required environment, dan free port.
2. Rancang response error JSON yang konsisten tanpa membocorkan secret.
3. Rancang workflow branch→review→merge→rollback untuk perubahan kecil.

## Level 5 — Debug / Workplace

Pilih tiga case dari [broken cases](../07_DEBUGGING/broken_cases.md). Tulis narrative lengkap dari symptom sampai prevention. Salah satunya wajib Git conflict atau port conflict.
