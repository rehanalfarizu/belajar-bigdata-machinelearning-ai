# Exercises

1. Gambar perjalanan `python app.py --config config.json` dari shell sampai process membaca file. Tandai working directory dan failure points.
2. Jelaskan perbedaan process, thread, concurrency, dan parallelism dengan satu contoh I/O dan satu contoh CPU-bound.
3. Diagnosa tiga kasus: file ada tetapi tidak ditemukan; port sudah dipakai; package terpasang tetapi import gagal. Tulis observasi yang harus dikumpulkan sebelum mengubah apa pun.
4. Rancang HTTP POST yang aman di-retry. Tentukan idempotency key, timeout, status codes, dan perilaku saat respons hilang.
5. Buat repository latihan, lakukan dua perubahan yang berkonflik, selesaikan konflik, lalu jelaskan keputusan isi final.
