# Problem-Solving Ladder — Computer Fundamentals

Problem tidak menyebut command yang harus dipakai. Tunjukkan reasoning dan evidence.

## Level 1 — Recall

Sebuah file Python tersimpan tetapi tidak ada process Python. Jelaskan state apa yang ada dan belum ada.

## Level 2 — Apply

Program perlu membaca `settings.json` dari project yang dapat dijalankan melalui terminal berbeda. Tentukan input contract dan observasi yang harus dicetak saat startup.

## Level 3 — Analyze

Browser tidak dapat membuka `localhost:9000`. Buat decision tree yang membedakan wrong host, no listener, port conflict, HTTP route error, dan invalid response.

## Level 4 — Design

Rancang `system-check` yang melaporkan interpreter, PID, cwd, input path, required environment presence, target host/port, dan hasil validasi JSON tanpa mencetak secret.

## Level 5 — Debug / Workplace

Service berjalan saat dieksekusi manual tetapi gagal di scheduler. Kamu hanya mendapat exit code, working directory berbeda, dan environment yang lebih sedikit. Susun investigation plan, minimal reproduction, evidence, safe fix, verification, serta regression prevention.
