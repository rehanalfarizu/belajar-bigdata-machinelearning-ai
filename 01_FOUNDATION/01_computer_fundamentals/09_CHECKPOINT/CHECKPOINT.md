# Checkpoint

Lulus jika tanpa catatan kamu dapat:

- membedakan path relatif/absolut dan process/thread;
- menjelaskan DNS→TCP→HTTP→JSON;
- menemukan interpreter dan environment yang aktif;
- memakai Git status/diff/log untuk membuktikan state;
- menulis diagnosis berbasis evidence untuk satu failure lingkungan.

Evidence: link project, transcript diagnosis, dan tanggal pada progress tracker.
