# Checkpoint — Computer Fundamentals

Jawab tanpa menyalin lesson. Jika tidak dapat menjelaskan, ulangi eksperimen terkait.

## Knowledge

- Gambar perjalanan `python app.py` dari shell ke process, CPU/memory, file, dan network.
- Bedakan program/process, cwd/source directory, IP/port, TCP/HTTP, JSON/API, serta working tree/staging/commit.

## Hands-on evidence

- dua process dari source sama dengan PID berbeda;
- relative path dari dua cwd;
- environment inheritance;
- local HTTP 200, HTTP 404, dan connection failure;
- branch dan conflict resolution;
- runnable `system-check` mini-project.

## Debugging evidence

Serahkan satu narrative lengkap: symptom, reproduce, observations, hypotheses, discriminating test, root cause, fix, verification, dan prevention.

## Reasoning challenge

Service bekerja manual tetapi gagal di scheduler. Jelaskan investigation order dan mengapa kamu memeriksa process context sebelum mengubah source.

## Gate

Lulus bila project berjalan dari clean instructions, evidence dapat diulang, dan kamu dapat menjawab “mengapa” pada setiap langkah. Catat lokasi bukti dan tanggal di progress tracker.
