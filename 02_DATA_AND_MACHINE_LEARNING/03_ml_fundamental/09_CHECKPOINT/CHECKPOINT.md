# Checkpoint — ML Fundamental

- Explain: generalization, split, baseline, leakage, bias/variance.
- Manual: satu algorithm dan metric.
- Build: preprocessing+model pipeline.
- Break/debug: target/preprocessing contamination.
- Evaluate: baseline, CV variability, locked test, error slices.
- Defend: why this model, why not alternative, limitations.

PASS bila pipeline tetap sah setelah reviewer mengubah cost atau deployment population.
