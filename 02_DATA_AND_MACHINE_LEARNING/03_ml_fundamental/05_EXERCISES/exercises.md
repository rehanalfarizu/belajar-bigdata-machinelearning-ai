# Exercises — Machine Learning Fundamental

1. Hitung baseline mean/majority dan metric manual.
2. Buat random, group, dan temporal split; jelaskan kapan masing-masing invalid.
3. Implementasikan simple linear fit lalu cocokkan library.
4. Bandingkan KNN raw/scaled dan tree raw/scaled.
5. Buat confusion matrix dari dua threshold.
6. Bandingkan MAE/RMSE pada satu outlier besar.
7. Buat learning curve dan diagnosis bias/variance.
8. Lakukan error slicing tanpa memakai test untuk development.

Untuk setiap exercise tulis prediction, evidence, explanation, modification, dan satu deliberate failure.
