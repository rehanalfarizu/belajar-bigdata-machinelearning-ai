# ML Fundamental — Problem Ladder
## Level 1 — Recall
Bedakan train/validation/test, parameter/hyperparameter, loss/metric, baseline/model.
## Level 2 — Apply
Hitung linear prediction, distance, confusion metrics, MAE/RMSE/R².
## Level 3 — Analyze
Validation AUC tinggi, pilot site baru gagal. Susun leakage/shift/threshold hypotheses dan experiments.
## Level 4 — Design
Rancang evaluation untuk repeated asset observations dengan future deployment.
## Level 5 — Workplace
Requirement berubah dari minimize average error ke avoid rare costly miss. Redesign target, metric, threshold, acceptance.
