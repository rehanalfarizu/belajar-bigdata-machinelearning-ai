# Data Mining — Problem Ladder
## Level 1 — Recall
Bedakan KDD, mining, support, confidence, lift, cluster, outlier.
## Level 2 — Apply
Hitung rule dari enam basket dan uji threshold sensitivity.
## Level 3 — Analyze
Cluster berubah total setelah scaling; buat hypothesis dan stability tests.
## Level 4 — Design
Rancang discovery→confirmation untuk alarm sequence lintas site.
## Level 5 — Workplace
Marketing meminta klaim kausal dari association. Susun response, evidence tambahan, safe decision, dan limitation.
