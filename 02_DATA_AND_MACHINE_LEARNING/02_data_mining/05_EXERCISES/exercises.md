# Exercises

1. Hitung support, confidence, dan lift lima candidate rules; tolak rule yang hanya mengikuti base rate.
2. Bandingkan clustering sebelum/sesudah scaling dan jelaskan perubahan membership.
3. Uji stability cluster terhadap seed dan bootstrap sample.
4. Rancang anomaly mining untuk fleet dengan operating modes berbeda tanpa mencampur rare-but-normal mode sebagai fault.
5. Audit 100 candidate patterns: tetapkan discovery/validation split dan cara melaporkan negative result.
