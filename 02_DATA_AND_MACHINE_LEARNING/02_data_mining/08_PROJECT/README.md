# Mini-Project — Transaction/Event Pattern Discovery

Pilih transaction atau ordered event data lokal.

1. Business understanding dan unit analisis.
2. Data contract/dedup/order.
3. Manual rule/transition calculation.
4. Simple implementation lalu library comparison bila tersedia.
5. Clustering/outlier atau sequence extension.
6. Threshold/seed/window sensitivity.
7. Confirmation split dan interpretation.

Deliverable: pattern catalog dengan support/stability, possible mechanism, operational use, false-discovery risk, dan kalimat eksplisit “association ≠ causation”.
