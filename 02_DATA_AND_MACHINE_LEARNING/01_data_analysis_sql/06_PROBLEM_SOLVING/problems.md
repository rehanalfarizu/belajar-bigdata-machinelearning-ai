# Data Analysis & SQL — Problem Ladder

Gunakan Problem→Known→Unknown→Assumptions→Hypotheses→Alternatives→Experiment→Evidence→Trade-off→Decision→Validation.

## Level 1 — Recall
Definisikan grain, schema, primary/foreign key, missing, dan window function dengan contoh sendiri.
## Level 2 — Apply
Tiga tabel raw memiliki mixed unit/timezone. Rancang contract dan reconciliation tanpa menimpa raw.
## Level 3 — Analyze
Revenue naik 18% setelah join. Temukan cardinality, row multiplier, unmatched key, dan test pembeda.
## Level 4 — Design
Rancang raw→validated→curated→SQL→report yang idempotent dan menjaga lineage.
## Level 5 — Workplace
Finance dan dashboard berbeda definisi “active asset”. Susun clarification, owner, effective time, backfill, acceptance evidence.
