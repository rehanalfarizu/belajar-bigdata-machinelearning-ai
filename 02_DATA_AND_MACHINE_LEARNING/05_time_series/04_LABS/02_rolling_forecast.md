# Lab 02 — Rolling Forecast dan Drift
## 1. TUJUAN
Mengevaluasi forecast per origin/horizon terhadap naive baseline.
## 2. PREREQUISITE
Lesson 03–05.
## 3. SETUP
Gunakan local synthetic trend-seasonal series.
## 4. PREDICTION BEFORE RUN
Prediksi error naive pada stable versus drift period.
## 5. LANGKAH PRAKTIKUM
Rolling-origin naive, moving average, optional ETS; plot ASCII error/time dan interval.
## 6. OBSERVATION
Catat MAE per horizon/period, coverage, width.
## 7. WHY
Average metric menyembunyikan degradation dan horizon effect.
## 8. MODIFICATION
Ubah window, season, drift magnitude.
## 9. FAILURE EXPERIMENT
Pilih model dari seluruh future period lalu klaim prospective.
## 10. DEBUGGING
Periksa origin, refit schedule, baseline, residual/time alignment.
## 11. WORKPLACE CONNECTION
Muncul pada capacity, inventory, energy, dan maintenance planning.
## 12. CHECKPOINT
Serahkan rolling evidence, baseline comparison, interval, drift trigger, limitation.
