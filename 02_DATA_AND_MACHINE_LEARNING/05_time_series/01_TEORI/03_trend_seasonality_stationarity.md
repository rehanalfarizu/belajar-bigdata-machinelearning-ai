# Lesson 03 — Trend, Seasonality, Stationarity, Autocorrelation

Trend adalah perubahan level jangka panjang; seasonality adalah pattern berulang pada periode; residual adalah sisa. Decomposition membantu reasoning tetapi bergantung pada period/assumptions.

Stationarity secara sederhana berarti statistical behavior relatif stabil. Differencing dapat mengurangi trend tetapi mengubah interpretation dan dapat berlebihan.

Autocorrelation mengukur linear relationship dengan lag, bukan causation. Plot/metric dapat terdistorsi trend.

Alternatives: model komponen eksplisit, tree dengan temporal features, state-space, atau neural model. Pilih dari horizon/data/operational constraint.
