# Mini-Project — Reproducible Neural Experiment

Pilih satu local/synthetic modality. Buat classical/simple baseline, manual neuron evidence, TensorFlow Dataset, explicit training loop, validation/checkpoint, reload test, learning curves, overfit experiment, one-variable regularization comparison, held-out evaluation, compute/latency note, and model card.

No download/GPU required for default path. DL harus dibenarkan oleh evidence, bukan asumsi.
