# Deep Learning — Problem Ladder
## Level 1 — Recall
Neuron, activation, loss, gradient, batch, epoch, checkpoint.
## Level 2 — Apply
Hitung forward/loss/one update manual.
## Level 3 — Analyze
Training turun, validation naik; buat hypothesis dan discriminating experiments.
## Level 4 — Design
Rancang training/evaluation/recovery untuk modality kecil tanpa download.
## Level 5 — Workplace
GPU unavailable dan latency budget dipotong. Bandingkan smaller model/classical baseline/distillation-like options tanpa menyebut tool sebagai jawaban.
