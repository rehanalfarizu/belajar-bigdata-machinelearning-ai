# Phase 2 — Data and Machine Learning

## WHY

AI yang dapat dipercaya dimulai dari grain, key, kualitas data, baseline, split, dan evaluasi yang benar—bukan dari algoritma paling kompleks.

## LEARN

SQL/EDA, data mining, supervised dan unsupervised learning, pipeline/tuning, time series, uncertainty, dan deep learning.

## ORDER

`01 Data Analysis & SQL` → `02 Data Mining` → `03 ML Fundamental` → `04 ML Advanced` → `05 Time Series` → `06 Deep Learning`.

## OUTPUT

Pipeline raw→validated→curated, analysis reproducible, model dengan baseline dan independent evaluation, serta laporan error/limitations.

## GATE

Lanjut bila dapat mencegah leakage, memilih metrik dari biaya kesalahan, menggunakan temporal split bila perlu, dan mereproduksi hasil dari clean environment.
