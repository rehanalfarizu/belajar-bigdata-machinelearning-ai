# ML Advanced — Problem Ladder
## Level 1 — Recall
Bedakan bagging/boosting, ranking/calibration, feature selection/regularization.
## Level 2 — Apply
Pilih threshold dari cost table dan hitung Brier/error.
## Level 3 — Analyze
Model terbaik rata-rata memiliki variance/latency tertinggi. Evaluasi evidence.
## Level 4 — Design
Rancang nested or clean validation untuk search+calibration+threshold.
## Level 5 — Workplace
Capacity human review turun separuh. Ubah policy tanpa tuning test dan siapkan rollback.
