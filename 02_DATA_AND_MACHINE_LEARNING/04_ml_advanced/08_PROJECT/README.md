# Mini-Project — Cost-Aware Model Selection

Bangun pipeline candidate model dengan valid CV, regularization/boosting option, calibration, cost threshold, imbalance handling di train fold, error slices, uncertainty/abstention, latency/memory measurement, dan decision record.

Definition of done: baseline tetap terlihat; test hanya sekali; table memuat mean/spread/cost/latency/size; selected model dapat lebih sederhana bila within tolerance; rollback trigger jelas.
