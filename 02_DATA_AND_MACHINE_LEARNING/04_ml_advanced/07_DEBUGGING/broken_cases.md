# Broken Cases — ML Advanced

1. Feature selection sebelum CV.
2. SMOTE pada test atau sebelum split.
3. Threshold dipilih pada test.
4. Calibration dilatih pada data model-fit yang sama.
5. Search overfit terhadap validation.
6. Random CV pada temporal/grouped data.
7. Importance dianggap causal.
8. Accuracy winner melanggar latency/memory.

Perbaikan harus menjaga fold boundary dan menghasilkan comparison table baru.
