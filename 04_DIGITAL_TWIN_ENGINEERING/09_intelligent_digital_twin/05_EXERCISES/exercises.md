# Exercises

1. Tulis recommendation object lengkap dengan validity window dan uncertainty.
2. Buat truth table command guard untuk stale state, high uncertainty, emergency, unauthorized actor, repeated command, dan out-of-envelope value.
3. Rancang shadow→canary→rollout→rollback model update dengan stop conditions.
4. Bandingkan rule, MPC/optimization, dan RL untuk satu sequential problem; pilih berdasarkan evidence.
5. Failure-inject network partition, operator absent, model timeout, contradictory sensors, dan rollback failure. Tetapkan safe/degraded behavior.
