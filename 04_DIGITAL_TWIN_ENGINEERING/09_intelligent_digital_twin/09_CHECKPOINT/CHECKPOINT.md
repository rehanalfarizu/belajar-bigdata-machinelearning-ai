# Checkpoint

Lulus bila demo membuktikan:

- recommendation tidak langsung menjadi command;
- hard constraints tidak dapat dilewati optimizer/model;
- stale/uncertain state memblokir atau menurunkan authority;
- setiap decision/command/outcome dapat ditelusuri;
- model update dapat dihentikan dan di-rollback;
- local safety tetap bekerja saat cloud/model gagal.
