# Machine Learning — Problem-Solving Ladder

## Level 1 — Recall
Jelaskan target, feature, split, baseline, metric, calibration, drift.
## Level 2 — Apply
Hitung prediction/metric manual dan pilih metric dari cost.
## Level 3 — Analyze
Offline metric tinggi, pilot gagal pada site baru. Susun competing hypotheses dan discriminating tests.
## Level 4 — Design
Rancang evaluation untuk entity berulang, time order, rare outcome, dan delayed label.
## Level 5 — Workplace
Capacity, latency, dan false-negative cost berubah setelah review. Buat decision table, revised policy, monitoring, rollback, limitation.
