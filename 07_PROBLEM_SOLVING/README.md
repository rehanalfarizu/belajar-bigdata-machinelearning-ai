# Phase 7 — Problem Solving

## WHY

Latihan chapter memberi konteks; problem di sini sengaja tidak menyebut tool atau algoritma agar decomposition, estimation, debugging, trade-off, design, dan decision benar-benar diuji.

## LEARN

Mendefinisikan masalah, menyatakan assumptions, membuat baseline, mengukur evidence, menguji counterexample, dan mempertahankan keputusan.

## ORDER

Mulai dari domain yang sedang dipelajari: `programming`, `math_statistics`, `data`, `machine_learning`, `systems`, lalu `digital_twin`.

## OUTPUT

Untuk tiap problem: problem restatement, constraints, assumptions, decomposition, baseline, tests/evidence, alternatives, trade-off, dan reflection.

## GATE

Usaha mandiri minimal 20–30 menit sebelum hints. Lulus bila reasoning tetap dapat dijelaskan ketika implementasi/angka diubah.

## PROJECT

Pilih minimal dua problem sebagai reasoning challenge untuk setiap phase pada [progress tracker](../PROGRESS_TRACKER.md).
