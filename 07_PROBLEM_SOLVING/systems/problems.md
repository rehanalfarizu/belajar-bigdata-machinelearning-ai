# Systems Problems

1. Consumer backlog naik ketika downstream lambat. Desain backpressure, retry, DLQ, recovery, dan SLO tanpa kehilangan auditability.
2. Cache menampilkan state lama setelah command. Pilih consistency contract, version/precondition, invalidation, dan user-visible behavior.
3. Deployment schema baru mematahkan satu producer lama. Rancang compatibility, migration, observability, dan rollback.
