# Programming Problems

1. Event file berukuran lebih besar dari memory memiliki baris rusak sporadis. Buat pemrosesan yang menghasilkan summary, quarantine, dan progress yang dapat dilanjutkan setelah crash.
2. Dua input memiliki timestamp berbeda timezone dan duplicate IDs. Tentukan kontrak merge, invariant, dan tests tanpa diberi struktur data.
3. Service lambat hanya saat traffic burst. Susun hypothesis tree, pengukuran, minimal reproduction, dan perubahan paling aman.
