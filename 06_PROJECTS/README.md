# Phase 6 — Monthly Projects

## WHY

Project memaksa materi lintas chapter bekerja bersama dalam satu outcome. Project besar dipisahkan dari materi agar pembelajar dapat membedakan guided learning dari engineering mandiri.

## LEARN

Scope, acceptance criteria, integration, tests, reproducibility, documentation, failure handling, observability, dan portfolio communication.

## ORDER

`month_01` → `month_02` → `month_03` → `month_04` → `month_05` → `month_06`.

## OUTPUT

Enam artefak runnable dengan evidence, culminating in a configurable Intelligent Digital Twin platform.

## GATE

Project lulus hanya bila acceptance criteria, tests, reasoning defense, dan reproducibility evidence terpenuhi—bukan karena demo terlihat berjalan.

## PROJECT

Folder ini adalah lokasi resmi seluruh monthly capstone. Mini-project tetap berada di chapter.
